# SHOP QA Portfolio Project

Manual QA portfolio project demonstrating practical testing of an e-commerce Checkout feature together with API and SQL testing examples.

## Skills Demonstrated

- Requirements Analysis
- Test Design
- Equivalence Partitioning
- Boundary Value Analysis
- Test Case Design
- Test Execution
- Bug Reporting
- Confirmation Testing
- Regression Testing
- Traceability
- REST API Testing
- Postman
- SQL
- Git / GitHub

## Web Testing — Checkout

Feature coverage includes:

- Authentication
- Cart quantity validation
- Checkout field validation
- Promo codes
- Delivery calculation
- Card and Cash payments
- Stock availability
- Order creation
- Duplicate order prevention

## API Testing

Booking API examples include:

- POST / GET / PUT / DELETE
- Positive and negative scenarios
- Authentication testing
- Response validation
- Request chaining using bookingid
- API bug investigation
